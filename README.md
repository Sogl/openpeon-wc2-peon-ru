# Орк-батрак из Warcraft II (Russian)

Пак для [peon-ping](https://github.com/PeonPing/peon-ping) на основе русской озвучки орка-батрака из Warcraft II (СПК).

## Звуки

В паке 22 реплики в 7 категориях:

| Категория          | Кол-во | Примеры                                                                   |
| ------------------ | -----: | ------------------------------------------------------------------------- |
| `session.start`    |      2 | `Готов вкалывать!`, `Что прикажете, повелитель?`                          |
| `task.acknowledge` |      3 | `Иток`, `Зокток`, `Глор-дук`                                              |
| `task.complete`    |      5 | `Работа выполнена!`, `Заг-заг`, `Лок-тар`                                 |
| `task.error`       |      3 | `На нас напали!`, `Они рушат наш город!`, `Ургх! (смерть)`                |
| `input.required`   |      3 | `Что-о-о?!`, `Р-р-ру?`, `Ур?`                                             |
| `resource.limit`   |      3 | `Ур-ур-уур!`, `У меня в брюхе урчит.`, `И-хи-хи! Щекотно!`                |
| `user.spam`        |      3 | `Полегче!`, `Промахнулся.`, `Я бы не делал этого, будь я на твоём месте!` |

## Установка

Устанавливать так:
```bash
peon packs use --install wc2_peon_ru
```

Затем переключить на этот пак:
```bash
peon packs use wc2_peon_ru
```

Дополнительные команды для проверки:
```bash
peon preview session.start
peon preview task.complete
```
